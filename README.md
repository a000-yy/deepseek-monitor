# DeepSeek 用量监控悬浮窗

一个常驻桌面的小悬浮窗，实时显示 DeepSeek 账户余额、花费进度和每日消费。

## 功能

- 当前余额（来自 DeepSeek 官方 `/user/balance` 接口，精确）
- 花费进度条：已花费 / 累计充值总额（充值总额可在设置中填写）
- 今日消费金额、今日 Token 用量、近 7 天消费柱状图
  - **官网实时模式**：同步官网登录令牌后，消费与 Token 直接读取 DeepSeek 官网统计，准确
  - **本地估算模式**：未同步时，消费按余额变化推算、Token 按单价估算
- 余额过低提醒：设置阈值后，余额低于阈值时弹出系统通知，余额数字变红
- 数据导出：一键将余额历史导出为 CSV（Excel 可直接打开）或 JSON
- 悬浮固定：一键让窗口「鼠标穿透」，界面不再响应点击，纯展示不挡住下方操作，可从托盘或快捷键解除
- 透明磨砂玻璃主题；全部操作集中在标题栏的单个菜单按钮，防误触
- 可拖动、置顶，系统托盘常驻

## 重要说明

1. **数据来源**：
   - **余额**：来自官方 `/user/balance` 接口，精确。
   - **消费 / Token**：推荐在设置中点 **登录并同步**，直接读取 DeepSeek 官网的真实每日消费与 Token 统计（走官网内部接口 `api/v0/usage/amount` 与 `usage/cost`）。该接口非官方公开 API，需要登录令牌，可能随官网改版失效，失效后重新同步即可。
   - 未同步官网令牌时自动退化为**本地估算**：消费按余额变化推算、Token 按综合单价估算，仅供参考。
2. **本地估算模式的今日消费**依赖程序运行：今日消费 = 今日起始余额 − 当前余额，首次运行当天可能显示为 0。
3. **花费进度**：需要在「设置」中填写**累计充值总额**，进度条才会按比例显示。

## 使用方法

### 1. 获取 API Key

访问 https://platform.deepseek.com/api_keys 创建一个 API Key（格式 `sk-...`）。

> 该接口只读余额，不会产生任何对话费用。

### 2. 启动

双击项目根目录下的 **`启动.bat`**，或在命令行执行：

```
npm start
```

### 3. 首次配置

首次启动会自动打开设置面板，填入：

- **API Key**：`sk-...`
- **累计充值总额**：例如你总共充值了 100 元就填 `100`（用于进度条）
- **余额提醒阈值**：例如填 `10`，余额低于 10 元时会弹出系统通知；填 `0` 关闭提醒
- 刷新间隔、提醒冷却、不透明度、开机自启可选

#### 官网实时数据（可选，推荐）

在设置面板点 **登录并同步**，在弹出的窗口内登录 DeepSeek 官网。登录成功后程序会自动捕获平台令牌，之后消费与 Token 将显示官网真实数据。点 **清除令牌** 可恢复本地估算模式。

> 登录窗口使用独立会话，不会保存你的密码，仅保存用于读取用量的登录令牌（在本机加密存储）。

标题栏右上角 **菜单 → 导出数据** 可随时将余额历史导出为 CSV 或 JSON。

点击「保存」后即开始按间隔自动刷新余额。

### 4. 操作

- 顶部区域按住可拖动窗口
- 标题栏右上角的 **菜单按钮**（≡）集中了全部操作：刷新数据、设置、导出数据、悬浮固定、隐藏到托盘、退出
- 托盘图标：左键显示/隐藏窗口；右键菜单同样可刷新、设置、悬浮固定、打开控制台、退出

### 5. 悬浮固定（鼠标穿透）

菜单 → **悬浮固定**，窗口进入「鼠标穿透」状态：界面不再响应任何点击，鼠标可直接操作窗口下方的程序，适合把用量当作纯展示的信息层。

解除方式（此时界面已无法点击，需用外部入口）：

- 托盘图标右键 → **取消悬浮固定**
- 全局快捷键 **Ctrl + Alt + D**

## 数据存放位置

配置与历史记录保存在：

```
%APPDATA%\DeepSeekMonitor\      （开发模式为 %APPDATA%\deepseek-monitor\）
├── config.json    # API Key、官网令牌（加密）、充值总额等配置
└── history.json   # 余额历史快照（最近 90 天）
```

API Key 与官网令牌仅保存在本机，并使用系统凭据保护（safeStorage）加密，不会上传到任何第三方服务器。

## 免安装 exe（已打包）

打包产物：

```
release\DeepSeekMonitor-1.4.0.exe   (约 71 MB，免安装，双击即用)
```

直接把该 exe 复制到任意位置双击即可运行，无需 Node.js 环境。

如需重新打包：

```
npm run icon    # 生成图标（build/icon.ico）
npm run dist    # 打包为免安装 exe，输出到 release\
```

> 说明：若打包时报 `Cannot create symbolic link`，是 electron-builder 解压 `winCodeSign`
> 需要符号链接权限所致（非管理员账户常见）。项目已在 `win.signAndEditExecutable: false`
> 中跳过该步骤，正常打包不受影响。

## 开机自动启动

在悬浮窗「设置」中勾选 **开机自动启动** 后保存即可。它会向系统写入一条登录启动项：

- 免安装 exe：直接指向该 exe
- 开发模式（`npm start`）：指向 electron 可执行文件并附带项目路径

取消勾选并保存即可关闭自启。

## 技术栈

Electron 33 · 原生 HTML/CSS/JS，无前端框架依赖。
